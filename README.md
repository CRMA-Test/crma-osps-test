# CRMA OSPS controlled test project

This deliberately small Node project exists to exercise evidence-backed security assessment. It
contains a mixture of positive controls, documented exceptions, and intentional gaps. The
repository is not a compliance claim or a production template.

Run the application with:

```sh
npm install
npm start
```

The generated executable under `test/fixtures/` is intentionally committed so an assessor can
distinguish generated executable presence from binary reviewability.
